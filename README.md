# OpticManager

Projet PHP de gestion d'un cabinet d'optique.

Fonctions principales :
- clients et patients
- produits, categories et fournisseurs
- commandes et ventes
- consultations et ordonnances
- rendez-vous
- stock
- utilisateurs
- dashboard et recherche

## Installation

1. Importer `les table.sql`, `les table_continue1.sql` et `lestable_continue2.sql`.
2. Modifier `connexion.php` si votre MySQL n'utilise pas `root` sans mot de passe.
3. Ouvrir `index-main.php`.

Le projet utilise PHP, MySQL et Bootstrap.
